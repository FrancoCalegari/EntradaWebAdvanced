Cloud Storage API

Sube, lista, reemplaza y descarga archivos en la nube con compatibilidad S3/MinIO y almacenamiento local. Proporciona URLs públicas instantáneas y flujos protegidos por proyecto.

Reglas de Subida y Multipart Form
Nombre de Campo Obligatorio en Multer:
• Para subidas masivas o creaciones en un proyecto (POST /projects/:id/files), el campo multipart/form-data debe llamarse exactamente files (plural, permite hasta 10 archivos simultáneos).
• Para reemplazar un archivo existente (PUT /files/:id), el campo del formulario debe llamarse file (singular).

Límite de Tamaño: Cada archivo individual tiene un tope fijado en 50 MB por seguridad del servidor. El sistema verifica la cuota de almacenamiento acumulada del usuario (1 GB Free / 120 GB User Only / 500 GB Premium) antes de consolidar la escritura.

Endpoints de Almacenamiento
MétodoEndpointDescripción
GET /api/v1/storage/projects Lista los proyectos de almacenamiento accesibles.
POST /api/v1/storage/projects Crea un nuevo proyecto contenedor de archivos.
GET /api/v1/storage/projects/:id/files Inventario de archivos en el proyecto, adjuntando la url pública de cada uno.
POST /api/v1/storage/projects/:id/files Subida multipart (campo files) de hasta 10 archivos al proyecto.
GET /api/v1/storage/files/:id Descarga o reproducción en flujo (*stream*) del archivo físico.
PUT /api/v1/storage/files/:id Reemplazo de archivo existente (campo file).
DEL /api/v1/storage/files/:id Borrado permanente del archivo del clúster y base de datos.
Subida de Archivos desde cURL y Python

Ejemplo en cURL: Adjuntando archivos usando el flag -F indicando el campo files:

curl -X POST "https://spiderwebargapi.com.ar/api/v1/storage/projects/1/files" \
  -H "X-API-Key: tu_api_key_aqui" \
  -F "files=@/ruta/local/documento.pdf" \
  -F "files=@/ruta/local/imagen.png"

Ejemplo en Python (requests):

import requests

headers = { "X-API-Key": "tu_api_key_aqui" }
url = "https://spiderwebargapi.com.ar/api/v1/storage/projects/1/files"

with open("manual_tecnico.pdf", "rb") as f:
    # El tuplo requiere la clave "files" para coincidir con el backend
    archivos = [("files", ("manual_tecnico.pdf", f, "application/pdf"))]
    res = requests.post(url, headers=headers, files=archivos)
    
if res.status_code == 201:
    info = res.json()["files"][0]
    print(f"Subido con éxito. URL pública: {info['url']}")
else:
    print(f"Error: {res.json().get('error')}")
